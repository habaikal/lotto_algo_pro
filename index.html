04 · ALGORITHM

왜 이 알고리즘이 최적인가

① 수축이 곧 정확도다

45개 기본빈도 + 2025개 전이쌍 + 45개 보너스쌍을 추정하면 표본(1243 전이)보다 모수가 많다. Laplace/Dirichlet 수축(α=10/20/10)으로 독립가설 쪽으로 당기지 않으면 필연적으로 과적합된다.

score = log base + 0.6·ΣPMI(prev) + 0.3·PMI(보너스)

② 균형 거부표집

합 98–177, 홀 2–4, 저구간(1–22) 2–4, 직전중복 0–2장. 역사적 기하분포 밖의 조합(전체의 희귀영역)을 제거해 기호편향을 없앤다.

softmax(score/1.5) → balanced() → 중복분산(교집합≤3)

③ 정직한 한계 고지

어떤 번호의 수학적 기대값도 동일하다. 본 엔진의 가치는 '당첨보장'이 아니라 '검증 가능한 최적 스코어링 + 재현 가능한 생성 + 투명한 백테스트'다. 유료 가치는 분석 깊이와 UX에서 나온다.
