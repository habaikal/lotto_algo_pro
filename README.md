# LOTTO QUANTUM ULTRA

수축 마르코프(EB-Markov) 기반 로또 분석·예측 웹앱. 빌드 없는 정적 사이트로,
GitHub Pages·Netlify·Vercel·Cloudflare Pages에 그대로 배포된다.

## 실행

```powershell
cd C:\app\lotto_algo_pro
npx serve .   # 또는: python -m http.server 8000
```

`index.html` 더블클릭(`file://`)으로는 데이터 파일을 읽지 못하므로 반드시 로컬 서버로 실행.

## 기능 요약

- 다음회 예측 조합 생성 (FREE 5 · PRO 500 · ULTRA 10,000게임)
- 희귀패턴 제거 필터 4종 (연속 4개+ · 직전 중복 4개+ · 전홀/전짝 · 극단합)
- CSV/TXT 일괄저장 · 전체복사 · SNS 전송 · 친구 초대(`?ref=`) 추적
- 신규 회차 입력 시 모델 재학습 → 다음회 예측 모드 자동 전환
- 분석 랩(빈도·전이·균형·백테스트) · 자가진단 10항목 · 역대 당첨 아카이브

## 데이터 갱신 (매주 토요일 추첨 후, 3가지 경로)

1. 앱 내 **신규 회차 입력** (가장 빠름 — 입력 즉시 재학습)
2. GitHub Actions 수동 실행 (`lotto-data` 워크플로에 회차·번호·보너스 입력)
3. `python scripts/update_lotto.py --add 1245 3,11,18,27,34,42 7` 후 커밋

무결성 검사는 `python scripts/update_lotto.py --check` (매주 토요일 자동 실행).
